# 🤖 Job Jarvis

AI-powered job discovery, matching, application preparation, and tracking.

## V0.1

- Streamlit dashboard
- Supabase persistence
- AI job matching
- Sample job source
- Application preparation foundation

## Setup

1. Create a Python 3.12 virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env`.
4. Add your OpenAI and Supabase credentials.
5. Run `streamlit run app.py`.

Never commit `.env` or API keys.
